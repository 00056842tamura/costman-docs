# スキル定義: パッケージ間依存チェック

## 目的
実装前後にパッケージ間の依存関係が正しいか確認し、循環依存や禁止依存を検出する。

## 前提条件
- .claude/rules/product-rules.md を読み込んでいること
- docs/architecture/stack-dependency.md を読み込んでいること

## 手順
1. 変更対象パッケージのimport文を全て確認する
2. docs/architecture/stack-dependency.md の「許可される依存関係」と照合する
3. 禁止された依存関係がないか確認する
4. 循環依存が発生していないか確認する
5. 問題がある場合は実装を止めて報告する

## 出力形式
```
## 依存チェック結果

### ✅ 問題なし
（問題がない場合）

### ❌ 問題あり
- [パッケージ名] → [依存先パッケージ名]
  理由: 禁止された依存関係 / 循環依存
  対処: （対処法を記載）
```

## 実行タイミング
- 新たなパッケージを import する実装を行う前
- PRレビュー前の最終確認時
