# スキル定義: セキュリティチェック

## 目的
コードのセキュリティ脆弱性を検査し、問題点と対処法を報告する。

## 前提条件
- .claude/rules/security-policy.md を読み込んでいること

## 手順
1. 対象ファイルを全て読み込む
2. 以下の観点でチェックする
   - ハードコードされたシークレット（APIキー・パスワード等）
   - SQLインジェクションの可能性
   - XSSの可能性
   - 認証・認可の抜け漏れ
   - 個人情報のログ出力
   - 外部入力のバリデーション不足
3. 問題点を重要度付きで報告する

## 出力形式
```
## セキュリティチェック結果

### 🚨 Critical（即時修正）
- [ファイル名:行番号] 脆弱性の種類: 内容 → 対処法

### ⚠️ Warning（修正必要）
- [ファイル名:行番号] 脆弱性の種類: 内容 → 対処法

### ✅ 問題なし
（問題がない場合）
```
