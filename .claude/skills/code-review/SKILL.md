# スキル定義: コードレビュー

## 目的
実装コードをレビュー基準に従って検査し、問題点と改善案を報告する。

## 前提条件
- .claude/rules/review-standards.md を読み込んでいること
- .claude/rules/coding-standards.md を読み込んでいること
- .claude/rules/security-policy.md を読み込んでいること

## 手順
1. 対象ファイルを全て読み込む
2. review-standards.md の各観点でチェックする
3. 問題点を以下の形式で列挙する
   - 重要度: 🔴高 / 🟡中 / 🟢低
   - ファイル名・行番号
   - 問題の内容
   - 改善案
4. 問題がない場合は「レビュー完了: 問題なし」と報告する

## 出力形式
```
## レビュー結果

### 🔴 高（必ず修正）
- [ファイル名:行番号] 問題内容 → 改善案

### 🟡 中（修正推奨）
- [ファイル名:行番号] 問題内容 → 改善案

### 🟢 低（任意改善）
- [ファイル名:行番号] 問題内容 → 改善案

### 総評
（全体的な品質評価と承認可否）
```

## 注意事項
- 個人攻撃的なコメントをしない（コードに対してコメントする）
- 改善案は具体的なコード例を示す
