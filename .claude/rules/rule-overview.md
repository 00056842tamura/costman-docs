# ルール 制約レベル凡例（Reacter / Springer 共通）

本プロジェクトのコード規約（Reacter / Springer 両フレームワーク共通）です。
コードに関する質問・改善/修正・レビュー・生成を行う際は、各ルール群に従ってください。

---

## 制約レベルの凡例

各ルールには以下の制約レベルが付与されています。

| 記号 | 分類 | 意味 |
|---|---|---|
| 🚫 | 禁止 (NEVER) | 絶対に行ってはならない |
| ⚠ | 非推奨 (AVOID) | 原則行わない。代替案を先に提示すること |
| ✅ | 必須 (ALWAYS) | 必ず適用すること |
| ✨ | 推奨 (PREFER) | 可能な限り適用すること |

加えて、各ルールファイルには規範ではない記述を整理する以下のセクションがあります。

- **条件付き事項（一覧）**: 「〜の場合は可」「〜できる」「〜を除く」等、適用条件付きの事項。
- **参考・推奨実装パターン**: やってよい/だめという規範ではない実装手順・API 解説。強制度は持ちません。
