# 04 DI・Bean クラスのメンバー変数

> 分類凡例: 🚫 禁止 / ⚠ 非推奨 / ✅ 必須 / ✨ 推奨 / 条件付き事項 / 参考・推奨実装パターン
> 適用範囲: Controller / Service / Repository（いずれもシングルトン Bean）に共通。

## 🚫 禁止 (NEVER)

### R-04-01 フィールドインジェクションをしない
フィールドインジェクションは禁止。依存 Bean は必ずコンストラクターインジェクションで受け取る（`@Autowired` は使用しない）。

### R-04-02 コンストラクターのオーバーロードをしない
コンストラクターのオーバーロードは禁止（1 クラスにつきコンストラクターは 1 つのみ）。
- 理由 / 背景: 何も考慮せずオーバーロードすると（DI 解決が破壊され）実行時エラーになる。

### R-04-05 状態を保持するメンバー変数を定義しない
Bean インスタンスを除き、状態を保持するメンバー変数を定義しない。
- 理由 / 背景: Controller/Service/Repository はシングルトンで使用されスレッド間共有になるため。

### R-04-06 static 変数を使用しない
`Logger` と定数 `static final` を除き、`static` 変数を使用しない。
- 理由 / 背景: スレッド間共有になるため。

## ⚠ 非推奨 (AVOID)

（なし）

## ✅ 必須 (ALWAYS)

### R-04-03 コンストラクター引数・メンバー変数の型はインターフェイス型とする
依存 Bean を受け取るコンストラクター引数の型、および保持するメンバー変数の型は、その実装が `implements` しているインターフェイス型とする。

### R-04-04 メンバー変数に final を付与する
保持するメンバー変数（依存 Bean など）には必ず `final` 修飾子を付与する。

## ✨ 推奨 (PREFER)

（なし）

## 条件付き事項

（なし）

## 参考・推奨実装パターン

> 依存 Bean はコンストラクター引数で受け取り、`final` のメンバー変数（インターフェイス型）に保持する典型構成。
