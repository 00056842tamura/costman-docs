# フック定義: issue 起票時の自動処理（プロダクト版）

> ⚠️ **このフロー定義は `/issue-init` スキルに統合されました。**
>
> issue 起票時の作業ディレクトリ生成は、以下のスキルで実行してください。
>
> - スキル定義: `.claude/skills/issue-init/SKILL.md`
> - 起動: `/issue-init`
>
> このファイルは過去の手動手順の記録として残しています。実運用では上記スキルを使用してください。

## トリガー
新しい issue が起票されたとき（外部チケット管理ツール起票後、Claude Code 上で作業開始時に手動実行）

詳細は `.claude/skills/issue-init/SKILL.md` を参照。
