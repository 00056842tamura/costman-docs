# 全社共通 業務用語辞書

## 読み込み指示
このファイルはissueインプット時に必ず最初に読み込むこと。
業務用語が出てきた場合は以下のマッピングに従って解釈すること。

## 用語マッピング

| 業務用語 | AI理解表現 | 補足・注意事項 |
|---------|-----------|--------------|
| ユーザー | システムにアカウント登録した個人 | 一般ユーザーと管理者ユーザーの2種類がある |
| アカウント | ユーザーが保有するシステム利用資格（メール・パスワード・プロフィール情報のセット） | 1メールアドレスにつき1アカウント |
| 登録 | 新規ユーザーがアカウントを作成する処理 | メール認証が必須 |
| ログイン | アカウントを持つユーザーが認証してシステムを利用開始する処理 | JWTトークンを発行する |
| ログアウト | ユーザーが認証セッションを終了する処理 | トークンを無効化する |
| プロフィール | ユーザーの表示名・アバター・自己紹介などの公開情報 | 本人のみ編集可能 |
| 管理者 | システム全体を管理できる特権ユーザー | ユーザー管理・設定変更が可能 |
| 権限 | ユーザーが実行できる操作の範囲を定義したルール | ロールベースで管理 |
| 通知 | システムがユーザーに送信するメッセージ（メール・画面内通知） | 種別ごとにON/OFF設定可能 |
| 設定 | ユーザーが自分の利用環境をカスタマイズする項目 | 言語・通知・プライバシーなど |

## 更新ルール
- 新たな業務用語が壁打ちで確定したら標準チームがここに追記する
- 既存の定義を変更する場合は全メンバーに周知する
