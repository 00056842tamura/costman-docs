## コード定義一覧

### ユーザー権限コード（`USER_ROLE`）

| 項目 | 内容 |
|---|---|
| タイプ | 固定長文字列 |
| 桁数 | 5〜6桁 |
| 内容 | ログイン API の応答に含まれる権限情報と比較し、利用者の権限を判定するために使用するコード |

| コード値 | 名称（意味） |
|---|---|
| `admin` | 管理者権限。管理者用データ取り込み画面を利用できる |
| `member` | 一般ユーザー権限。管理者用データ取り込み画面は利用できない |

---

### 予実区分フラグ（`YOJITSU_*_FLG`）

| 項目 | 内容 |
|---|---|
| タイプ | 固定長文字列（1桁） |
| 桁数 | 1桁 |
| 内容 | 収支データが計画・実算・利用率のいずれであるかを表す区分。`0` から始まる連番の1桁数字文字列 |

| コード値 | 名称（意味） |
|---|---|
| `0` | 計画（`YOJITSU_KEIKAKU_FLG`）。表示名: `計画` |
| `1` | 実算（`YOJITSU_JISSAN_FLG`）。表示名: `実算` |
| `2` | 利用率（`YOJITSU_USAGE_FLG`）。表示名: `利用率` |

工番別収支データ参照画面の収支一覧・合計表のグリッド行区分、および並び替え条件「予実」ドロップダウンの選択値として使用する。

---

### ハンドリング対象 HTTP ステータスコード（`HANDLING_STATUS_CODE`）

| 項目 | 内容 |
|---|---|
| タイプ | 配列（数値） |
| 桁数 | 3桁×4件 |
| 内容 | 共通の通信エラー処理で個別にハンドリングする対象の HTTP ステータスコードの一覧 |

| コード値 | 名称（意味） |
|---|---|
| `400` | 不正なリクエスト |
| `401` | 未認証（3秒後に自動的にログアウト処理を行う契機となる） |
| `404` | 未検出 |
| `409` | 競合 |

---

### メッセージ区分（トースト通知）

| 項目 | 内容 |
|---|---|
| タイプ | 固定長文字列 |
| 桁数 | 可変 |
| 内容 | トースト通知の表示種別を表す区分。未指定の場合は `information` として扱う |

| コード値 | 名称（意味） |
|---|---|
| `information` | 通知（背景色 `#87ceebee`・枠線色 `#0047ab`） |
| `warning` | 警告（背景色 `#fffbeb`・枠線色 `#d97706`） |
| `error` | エラー（背景色 `#f08080ee`・枠線色 `#bb2121`） |

## フラグ・区分の定義に関する注意事項

- 予実区分フラグは `0`〜`2` の数字文字列で管理し、真偽値（`true`/`false`）は使用しない。
- 権限コード（`USER_ROLE`）を新規追加する場合は、既存値（`admin`／`member`）との重複がないことを確認する。
- 廃止したコード値はコメント（備考）に廃止日を記録し、定義から除去しない（旧設計書には廃止コードの記載はない）。
