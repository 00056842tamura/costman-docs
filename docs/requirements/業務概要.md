## 1. システム概要

コスト管理システムは、工番（プロジェクト番号）単位の収支データおよびコスト利用率を参照するための社内向け Web アプリケーションである。社員活動情報・単価データ・ソフ仮（ソフトウェア仮設）マンパワー費・プロ管（プロジェクト管理）計画値といった複数のデータソースを取り込み、工番別の収支（計画・実算・利用率）を集計して画面上に表示する。

フロントエンドは React（Reacter）による SPA として実装され、バックエンドの Web API（`/login`・`/kobanbetsu-shushi` 等）と通信して認証・データ取得・データアップロードを行う。認証はセッション（Cookie）方式で、ブラウザのローカルストレージにもユーザー情報を保持することで再読み込み後もログイン状態を維持する。

## 2. 業務フロー概要

1. 利用者はログイン画面でユーザーID・パスワードを入力し、認証を行う。
2. 認証後、メニュー画面から「工番別収支データ参照」「コスト利用率参照」「プロ管取込（データ取り込み画面）」「管理者用データ取り込み」のいずれかの機能を選択する。
3. データ取り込み担当者（管理者権限を持つ利用者）は、社員活動情報・単価データ・ソフ仮データを CSV 形式で取り込み、コスト集計の元データを更新する。
4. 一般利用者は、取り込まれたデータをもとに工番別の収支・コスト利用率を検索・参照する。

システム化業務フローの詳細な図は `docs/requirements/システム化業務フロー.md` に要件ID単位で作成済みである（旧設計書には業務フロー図の記載がないため、フロントエンド実装コードの画面遷移・API呼び出しから再構成した）。

## 3. 利用者・権限

| 利用者区分 | 役割・権限 |
|---|---|
| 一般ユーザー（`member`） | 工番別収支データ参照・コスト利用率参照・データ取り込み画面（プロ管取込）を利用できる。管理者用データ取り込み画面は利用できない |
| 管理者（`admin`） | 一般ユーザーの機能に加え、管理者用データ取り込み画面（社員活動情報・単価データ・ソフ仮データの CSV 取り込み）を利用できる |

権限情報はログイン API の応答（`authorities` の先頭要素）から取得し、ブラウザのローカルストレージに保持される。クライアント側の権限情報は改変され得るため、画面への到達制御（ルーティングガード）は抑止的な措置であり、実際の認可判定は API 側（バックエンド）で行う想定である（詳細は `docs/decisions` 等、バックエンド側 SS 工程で別途確定する）。

## 4. システム範囲

### 4.1 対象範囲

- ログイン認証（独自 ID・パスワード方式）
- メニューからの各機能への遷移
- 工番別収支データの参照（工番検索を含む）
- コスト利用率の参照
- CSV データの取り込み（社員活動情報・単価データ・ソフ仮データ・プロ管データ）
- CSV 変換マクロファイルのダウンロード

### 4.2 対象外範囲

- 帳票（PDF）出力機能（旧設計書に記載がないため対象外）
- CSV データの生成元システム（社員活動情報システム等）側の仕様（フロントエンドのコードから判定できないため「不明」として扱う）

## 6. 用語定義

| 用語 | 定義 |
|---|---|
| 工番 | プロジェクト（工事番号）を表すコード。親番（6桁）と子番（2桁）で構成される |
| プロ管（計画値） | プロジェクト管理システムにおける計画値データ。CSV 変換マクロで CSV 化し、データ取り込み画面から取り込む |
| ソフ仮 | ソフトウェア仮設マンパワー費データの略称 |
| 速報値 | 実算データのうち、社員活動情報システムのデータと単価から算出した速報段階の値。確定値ではないことを画面上で `(*)` により明示する |
| 予実区分 | 収支データの区分。計画（`0`）・実算（`1`）・利用率（`2`）の3種 |
