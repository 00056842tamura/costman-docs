# 要件定義書（R007）

## メタ情報
- 要件ID: R007
- 要件名: 社員活動情報・単価・ソフ仮データの取り込み（管理者向け）
- 案件キー: （本移行では未設定）
- SA issue-id: （なし。`old_docs/管理者用 データ取り込み画面(ADMIN_TORIKOMI)/` からの移行）
- 作成日: 2026/08/20
- 最終更新日: 2026/08/20

## 目的・背景

管理者権限を持つ利用者が、社員活動情報データ・単価データ・ソフ仮データをそれぞれ独立したフォームからCSVで取り込む。

## 対象ユーザー

管理者権限（`admin`）を持つ、ログイン済みの利用者のみ。

## 要求一覧

| # | 要求内容 | 優先度 | 備考 |
|---|---------|-------|------|
| 1 | 「年月」とCSVファイルを指定して社員活動情報データを取り込む | 高 | 社活データアップロードAPI |
| 2 | CSVファイルを指定して単価データを取り込む | 高 | 単価データアップロードAPI |
| 3 | 「年度」とCSVファイルを指定してソフ仮データを取り込む | 高 | ソフ仮データアップロードAPI |
| 4 | 3つのフォームは互いに独立し、1つの取り込み完了は他フォームの入力に影響しない | 中 | |
| 5 | 管理者権限を持たない利用者はこの画面に到達できない | 高 | URL直接指定時もメニュー画面へリダイレクト |

## 受け入れ条件
- [ ] 管理者権限で各フォームからCSVを取り込むと、登録件数がトースト通知される
- [ ] 一般ユーザー権限でこの画面のURLに直接アクセスした場合、メニュー画面へリダイレクトされる
- [ ] 未ログインの場合、ログイン画面へ遷移する

## 非機能要件

- パフォーマンス: 特になし
- 可用性: 特になし
- セキュリティ: ログイン必須かつ管理者権限必須。権限判定はクライアント側の抑止的制御に留まり、実際の認可判定はAPI側（3つのアップロードAPI）で行う
- データ保持: なし

## 制約事項

権限情報はブラウザのローカルストレージ由来であり改変され得るため、ボタン非表示とルーティングガードの二重制御とする。
