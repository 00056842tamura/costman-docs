## front-intra-001 トップページ

### 画面概要

未ログインでも表示できる入口ページ。お知らせ一覧・お問い合わせ先・エラー報告用メーラー起動リンクを表示し、「メニュー画面へ」ボタンからメニュー画面（未ログイン時はログイン画面）へ遷移する。

### 画面項目定義

| No. | 項目名 | 入力種別 | 型 | 桁数 | 必須 | 初期値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | お知らせ一覧 | 表示のみ | 文字列 | - | - | - | 日付＋お知らせ内容のリスト。ソースコード内に静的にハードコードされている（バックエンドAPIからの取得ではない） |
| 2 | お問い合わせ先 | 表示のみ | 文字列 | - | - | - | 担当者名・内線番号のテーブル。ソースコード内に静的にハードコードされている |
| 3 | メールはこちら | リンク（`mailto:`） | 文字列 | - | - | - | クリックすると宛先・件名（「コスト管理システムのエラーの報告／ご要望」）を設定済みのメーラーが起動する |

### 入力フォーマット記法

| 記法 | 意味 | 例 |
|---|---|---|
| `＜YYYY/MM/DD＞：` | お知らせ日付の表示形式 | `＜2025/02/28＞：` |

### ボタン定義

| ボタン名 | 動作 | 遷移先 |
|---|---|---|
| メニュー画面へ | メニュー画面へ遷移する | メニュー画面（未ログイン時はルーティング保護によりログイン画面） |
| メールはこちら | エラー報告・要望送付用のメーラーを起動する（`target="_blank"`） | 外部（メーラー） |

### バリデーション

該当なし（入力項目を持たない画面）。

## front-intra-002 ログイン画面

### 画面概要

ユーザーID・パスワードを入力して認証を行う画面。認証成功時はセッション情報（`username`・`authorities`）を受け取り、ログイン状態をアプリケーション（Context）とブラウザに保持したうえで、遷移元画面（`from` が指定されている場合）またはメニュー画面へ遷移する。

### 画面項目定義

| No. | 項目名 | 入力種別 | 型 | 桁数 | 必須 | 初期値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | ユーザーID（`userId`） | テキスト | 文字列 | 8 | ○ | なし | `autoComplete="off"`。onBlur（フォーカス離脱）時にバリデーションを実行 |
| 2 | パスワード（`password`） | テキスト（`type="password"`） | 文字列 | - | ○ | なし | `autoComplete="off"`。桁数上限はコード上に明記なし（不明・旧設計書に記載なし） |

### 入力フォーマット記法

| 記法 | 意味 | 例 |
|---|---|---|
| `XXXXXXXX` | 半角英数字8桁以内（ユーザーID） | `A0001234` |
| `********` | パスワード（マスク表示） | `********` |

### ボタン定義

| ボタン名 | 動作 | 遷移先 |
|---|---|---|
| ログイン（submit） | ログインAPI（`POST /login`）を呼び出し、認証成功時にログイン状態を保持する | 遷移元画面（`from` 指定時）／メニュー画面（`from` 未指定時） |
| Topページ | 認証を行わずトップページへ遷移する | トップページ |

### バリデーション

| 項目名 | チェック内容 | エラーメッセージ |
|---|---|---|
| ユーザーID | 必須チェック | `{ユーザーID}を入力して下さい。` |
| ユーザーID | 8文字以下チェック | `{ユーザーID}は8文字以下で入力して下さい。` |
| パスワード | 必須チェック | `{パスワード}を入力して下さい。` |
| （サーバー側）ユーザーID／パスワード | 認証失敗（ID・パスワード不一致） | `ユーザーIDまたはパスワードが正しくありません。` |

### レイアウトイメージ

```
+--------------------------------------------------+
|  ログイン                                          |
+--------------------------------------------------+
|  ユーザーID  [________________]                    |
|  （エラーメッセージ）                               |
|                                                    |
|  パスワード  [________________]                    |
|  （エラーメッセージ）                               |
|                                                    |
|          [ ログイン ]   [ Topページ ]               |
+--------------------------------------------------+
```

## front-intra-004 工番別収支データ参照画面

### 画面概要

工番コード（親番・子番）と年度を条件に、社員ごとの計画・実算収支データと合計（計画・実算・利用率）を検索・参照する画面。工番が不明な場合は「工番検索」ボタンから子ダイアログ（工番検索ダイアログ）を開いて工番を検索・選択できる。検索結果は画面内で「予実」「ソートする列」「並び順」を指定して並び替えられる（再検索は発生しない）。

### 画面項目定義

| No. | 項目名 | 入力種別 | 型 | 桁数 | 必須 | 初期値 | 備考 |
|---|---|---|---|---|---|---|---|
| 1 | 工番コードの親番（`kobanCdOya`） | テキスト | 数字（文字列） | 6（固定） | ○ | なし | 半角数字のみ |
| 2 | 工番コードの子番（`kobanCdKo`） | テキスト | 数字（文字列） | 2（固定） | ○ | なし | 半角数字のみ |
| 3 | 工番検索 | ボタン | - | - | - | - | 工番検索ダイアログを開く |
| 4 | 年度（`nendo`） | プルダウン | 文字列（4桁） | 4（固定） | ○ | 選択肢の最新年度 | 選択肢は当年度を含む直近3年度（`COMMON_CONFIG.NENDO_COUNT`）。年度の判定は4月始まり |
| 5 | 収支検索（submit） | ボタン | - | - | - | - | 工番別収支検索API（`GET /kobanbetsu-shushi`）を呼び出す |
| 6 | 工番名（`kobanNm`） | 表示のみ（`readOnly`） | 文字列 | - | - | 空 | 検索結果の工番名を表示する。入力不可 |
| 7 | ソート（予実）（`sortingYojitsuFlg`） | プルダウン | 文字列 | - | - | 空 | 「計画」「実算」を選択。部署コード・社員番号・氏名でソートする場合は未選択でよい |
| 8 | ソート（列）（`sortingColumn`） | プルダウン | 文字列 | - | - | 「社員番号」 | 部署コード・社員番号・氏名・4月〜3月・合計から選択 |
| 9 | ソート（順序）（`sortOrder`） | プルダウン | 数値 | - | - | 「昇順」（`1`） | 昇順（`1`）／降順（`-1`） |
| 10 | 並び替え | ボタン | - | - | - | - | 通信を発生させず、画面内で収支一覧を並び替える |
| 11 | 登録日時一覧 | 表示のみ | 日時 | - | - | `----/--/-- --:--:--` | 社員活動情報／単価データ（社員）／単価データ（協力会社）／プロ管（計画値）／ソフ仮マンパワー費の登録日時。「プロ管（計画値）」が未登録の場合は「プロ管取込」リンクを表示 |
| 12 | 収支一覧グリッド | 表示のみ（グリッド） | - | - | - | 空 | 部署・社員番号・氏名・予実・4月〜3月・合計。速報値を含む月は列見出しに `(*)` を付与 |
| 13 | 合計表グリッド | 表示のみ（グリッド） | - | - | - | 初期値0（計画・実算・利用率の3行） | 収支一覧グリッドと横スクロールが同期する |
| 14 | メニューへ | ボタン | - | - | - | - | メニュー画面へ遷移する |

### 工番検索ダイアログ（子ダイアログ）項目定義

「工番検索」ボタンで開くダイアログ（`KobanSearchDialog`）。

| No. | 項目名 | 入力種別 | 型 | 桁数 | 必須 | 初期値 | 備考 |
|---|---|---|---|---|---|---|---|
| D1 | 工番コード（親番）（`kobanCdOya`） | テキスト | 数字（文字列） | 6以内 | - | 空 | 半角数字のみ。空文字を許容（前方一致検索・ツールチップ表示） |

## front-intra-005 コスト利用率参照画面

### 画面概要

工番コード（親番・子番・工番名）・年度・部署を条件に、工番ごとの月別コスト利用率（対工期・全体・4月〜3月）を検索・参照する画面。一覧行をダブルクリックすると、当該工番・年度を引き渡して工番別収支データ参照画面へ遷移する。

| 2 | 工番コードの子番（`kobanCdKo`） | テキスト | 数字（文字列） | 2（固定・入力する場合） | - | 空 | 半角数字のみ。空文字を許容 |
| 3 | 年度（`nendo`） | プルダウン | 文字列（4桁） | 4（固定） | ○ | 選択肢の最新年度 | 選択肢は当年度を含む直近3年度 |

| 6 | 工番名（`kobanNm`） | テキスト | 文字列 | 15以内 | - | 空 | 空文字を許容 |
| 7 | ソート（列）（`sortingColumn`） | プルダウン | 文字列 | - | - | 「工番コード」 | 工番コード・工番名・全体・対工期・4月〜3月から選択 |
| 8 | ソート（順序）（`sortOrder`） | プルダウン | 数値 | - | - | 「昇順」（`1`） | 昇順（`1`）／降順（`-1`） |

| 12 | メニューへ | ボタン | - | - | - | - | メニュー画面へ遷移する |
