# 要件定義書（R005）

- 最終更新日: 2026/08/20

## 目的・背景

工番コード・工番名・年度・部署コードを条件に、工番ごとの月別コスト利用率を一覧参照する。一覧から工番別収支データ参照画面への遷移も行う。

## 対象ユーザー

ログイン済みの利用者（一般ユーザー・管理者）。権限（`role`）による表示制御はない。

## 要求一覧

| # | 要求内容 | 優先度 | 備考 |
|---|---------|-------|------|
| 1 | 工番コード・工番名・年度・部署コードを条件にコスト利用率を検索する | 高 | コスト利用率検索API |
| 2 | 部署コードの選択肢は初期表示時にAPIから取得する | 中 | 部署コード一覧取得API |
| 3 | 一覧のセルは値（100超／100／100未満／データなし）により背景色を変える | 中 | |
| 4 | 一覧を「ソート」「並び順」で並び替える | 中 | 通信を伴わない画面内並び替え |
| 5 | 一覧行のダブルクリックで工番別収支データ参照画面へ遷移する | 中 | 工番コード・年度を引き渡す |
| 6 | 「プロ管（計画値）」が未登録の場合、「プロ管取込」リンクを表示する | 低 | |
| 7 | 参照専用機能である | 高 | 機能制限パターン: 参照のみ |

## 受け入れ条件
- [ ] 検索条件に一致するコスト利用率データが一覧表示される
- [ ] 一覧行をダブルクリックすると工番コード・年度を引き渡して工番別収支データ参照画面へ遷移する（工番コードが存在する行のみ）
- [ ] セルの値に応じて背景色が変わる

## 非機能要件

- パフォーマンス: 特になし
- 可用性: 特になし
- セキュリティ: ログイン必須。権限（`role`）による制御なし
- データ保持: なし

## 制約事項

表示する金額は確定している金額のみである旨を画面下部に注記する。

## 除外範囲

データの登録・更新・削除・出力は対象外。
