## front-intra-006 データ取り込み画面

| 項目 | 内容 |
|---|---|
| 機能ID | front-intra-006 |
| 要件ID | R006 |
| スタック | frontend |
| 種別 | 画面 |

### 機能概要

利用者が選択したフォルダ配下のプロ管データ（CSV）をプロ管データアップロードAPI（bs-006）へまとめて送信し取り込む。CSV変換マクロファイル（Excelマクロ）のダウンロードも提供する。URL: `/torikomi`。ログイン必須、権限による制限なし。

### 入力

| 種別 | 名称 | 概要 |
|---|---|---|
| 画面 | プロ管データファイル | フォルダ単位で選択（`webkitdirectory`＋`multiple`）。`text/csv` に絞り込み |

### 出力

| 種別 | 名称 | 概要 |
|---|---|---|
| API | プロ管データアップロードAPI（bs-006） | 選択ファイル全件を同一項目名 `prokanDatas` で送信 |
| ファイル | CSV変換マクロファイル | `プロ管計画値_CSV化ツール(1.1版).xlsm` のダウンロード |

### 処理概要

1. 「フォルダ選択」ボタンでフォルダ選択ダイアログを開き、配下ファイル全件を選択する。ファイル名欄には選択フォルダ名を表示する。
2. 選択時に単体項目チェック（未選択・空ファイル混在・CSV形式なし）を行う。
3. 「送信」ボタン押下でチェック成功時、選択ファイル全件をフォームデータに変換しプロ管データアップロードAPI（bs-006）へ送信する。
4. 成功時、登録件数をトースト通知（`INFOMATION_SUCCESS_REGIST`）し、選択状態をクリアする。失敗時は選択状態を保持し再送信可能とする。
5. 「CSV変換マクロをダウンロード」ボタンでExcelマクロファイルをダウンロードする。
6. 「メニューへ」ボタンでメニュー画面へ遷移する。

### 特記事項

- ファイルの内部構造（文字コード等）はサーバ側解析のため画面側からは判定できない。
- 選択されたファイルの一覧・件数は画面に表示しない。
