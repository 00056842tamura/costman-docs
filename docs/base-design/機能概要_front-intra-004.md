## front-intra-004 工番別収支データ参照画面

| 項目 | 内容 |
|---|---|
| 機能ID | front-intra-004 |
| 要件ID | R004 |
| スタック | frontend |
| 種別 | 画面 |

### 機能概要

工番コード（親番・子番）・年度を検索条件に、工番別収支検索API（bs-005）で収支データを検索し、収支一覧・合計表・登録日時を表示する。工番検索ダイアログ（工番検索API bs-004 使用）から工番を検索・選択できる。URL: `/kobanbetsu-shushi`。ログイン必須・参照専用。

### 入力

| 種別 | 名称 | 概要 |
|---|---|---|
| 画面 | 検索条件 | 工番コードの親番（半角数字6桁）・子番（半角数字2桁）・年度（当年度を含む3年度分） |
| 画面 | 並び替え条件 | 予実・ソートする列・並び順 |
| 画面 | 工番検索ダイアログの検索条件 | 工番コードの親番（前方一致）・子番（完全一致）・工番名（部分一致） |

### 出力

| 種別 | 名称 | 概要 |
|---|---|---|
| API | 工番別収支検索API（bs-005） | 検索条件を送信 |
| API | 工番検索API（bs-004） | ダイアログの検索条件を送信 |
| 画面 | 収支一覧・合計表・登録日時表 | 検索結果を表示 |

### 処理概要

1. 検索条件の単体項目チェックを行い、成功時に工番別収支検索API（bs-005）へ送信する。
2. 応答の工番名・登録日時（5件）・収支レコード（計画行・実算行に展開）・合計表（計画・実算・利用率）・速報値フラグを反映する。
3. 検索結果は画面内で「予実」「ソートする列」「並び順」により並び替え可能（通信を伴わない）。
4. 「工番検索」ボタンから工番検索ダイアログを表示し、工番検索API（bs-004）で検索、行選択でその工番コードを検索条件に設定し即時再検索する。
5. 「プロ管（計画値）」の登録日時が未登録の場合、「プロ管取込」リンクからデータ取り込み画面（front-intra-006）へ遷移できる。
6. 「メニューへ」ボタンでメニュー画面へ遷移する。

### 特記事項

- 参照専用機能（登録・更新・削除・出力は行わない）。
- 速報値（`(*)`表示）は確定値ではない旨をフッタに注記する。
