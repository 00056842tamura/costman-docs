## front-intra-005 コスト利用率参照画面

| 項目 | 内容 |
|---|---|
| 機能ID | front-intra-005 |
| 要件ID | R005 |
| スタック | frontend |
| 種別 | 画面 |

### 機能概要

工番コード・工番名・年度・部署コードを検索条件に、コスト利用率検索API（bs-003）で月別コスト利用率を検索し一覧表示する。部署コードの選択肢は部署コード一覧取得API（bs-001）から取得する。URL: `/cost-riyoritsu`。ログイン必須・参照専用。

### 入力

| 種別 | 名称 | 概要 |
|---|---|---|
| 画面 | 検索条件 | 工番コードの親番・子番・工番名・年度・部署コード |
| 画面 | 並び替え条件 | ソート（工番コード・氏名・全体・対工期・月別）・並び順 |

### 出力

| 種別 | 名称 | 概要 |
|---|---|---|
| API | コスト利用率検索API（bs-003） | 検索条件を送信 |
| API | 部署コード一覧取得API（bs-001） | 初期表示時に部署コードの選択肢を取得 |
| 画面 | コスト利用率一覧・登録日時表 | 検索結果を表示 |
| 画面 | 工番別収支データ参照画面（front-intra-004） | 一覧行ダブルクリックで遷移 |

### 処理概要

1. 初期表示時、年度の選択肢（当年度含む3年度分）を生成し、部署コード一覧取得API（bs-001）で部署コードの選択肢を取得する。
2. 検索条件の単体項目チェック後、コスト利用率検索API（bs-003）へ送信する。
3. 応答の登録日時一覧・コスト利用率一覧（`usageRate`）を表示する。セルは値（100超／100／100未満／データなし）で背景色を変える。
4. 一覧は「ソート」「並び順」で画面内並び替え（通信を伴わない）。
5. 一覧行のダブルクリックで、工番コード・年度を state として引き渡し工番別収支データ参照画面（front-intra-004）へ遷移する（工番コードが存在する行のみ）。
6. 「プロ管（計画値）」が未登録の場合、「プロ管取込」リンクからデータ取り込み画面（front-intra-006）へ遷移できる。
7. 「メニューへ」ボタンでメニュー画面へ遷移する。

### 特記事項

- ログイン中のユーザーの権限（`role`）による表示制御は行わない。
- 表示する金額は確定している金額のみである旨を画面下部に注記する。
