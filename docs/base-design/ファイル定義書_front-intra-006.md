|---|---|---|---|---|---|---|---|
| 不明 | 不明 | | | | | | 列構成はサーバ側で解析するため、画面側に列定義がない |

### バリデーション仕様（画面側）

| No. | 項目名 | チェック内容 | エラー時の扱い |
|---|---|---|---|
| 1 | プロ管データファイル | ファイルが1件も選択されていない場合エラー | メッセージ `ERROR_REQUIRED_SELECT`。送信しない |
| 2 | プロ管データファイル | 選択されたファイルのうち1件でも大きさが0のものがある場合エラー | メッセージ `ERROR_NOT_EMPTY_FILE`。送信しない |
| 3 | プロ管データファイル | 選択されたファイルのうち種別が `text/csv` のものが1件もない場合エラー | メッセージ `ERROR_INVALID_FILE_TYPE`。送信しない |

補足:
- データ取り込み画面（front-intra-006）の「プロ管データ CSV取り込み」で選択し、プロ管データアップロードAPI（bs-006、`PUT /upload-prokandata`）へ送信する。
- ファイルではなくフォルダを選択する。選択したフォルダ配下のファイルを複数件まとめて送信する（同一物理名 `prokanDatas` で繰り返し設定）。
- ファイル選択欄は `text/csv` のみを選択候補として表示する。ファイルの大きさの上限は画面側では検証しない。
- ファイル名欄には、選択されたフォルダ名（1件目のファイルの相対パスの先頭）を表示する。
- CSV形式以外のファイルが含まれていても、選択されたファイルを絞り込まずに全件送信する（取り込み対象の判定はサーバ側で行う）。

### サンプルデータ

不明（列構成がサーバ側の仕様のため、サンプルデータは提示できない）。
