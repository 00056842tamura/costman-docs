## front-intra-002 ログイン画面

| 項目 | 内容 |
|---|---|
| 機能ID | front-intra-002 |
| 要件ID | R002 |
| スタック | frontend |
| 種別 | 画面 |

### 機能概要

入力された「ユーザーID」「パスワード」をログインAPI（bs-002）へ送信し認証を行う。URL: `/login`。ログイン認証による保護の対象外であり、未ログインでも表示できる（セッションタイムアウト監視も行わない）。

### 入力

| 種別 | 名称 | 概要 |
|---|---|---|
| 画面 | ログインフォーム | ユーザーID（最大8桁）・パスワード |
| 遷移パラメータ | 遷移元パス（`from`） | 保護画面へ未ログインでアクセスした場合にルーティング保護から渡される |

### 出力

| 種別 | 名称 | 概要 |
|---|---|---|
| API | ログインAPI（bs-002） | ユーザーID・パスワードをフォームデータで送信 |
| 画面 | メニュー画面／遷移元の画面 | 認証成功時の遷移先 |

### 処理概要

1. 「ユーザーID」「パスワード」の単体項目チェックを行う。
2. ログインAPI（bs-002）へフォームデータ形式で送信する。
3. 成功時、応答の `username` をユーザーID、`authorities` 先頭要素の `authority` を権限として保持し（React Context ＋ ローカルストレージ `auth`）、遷移元パス（`from`）があればその画面へ、なければメニュー画面（`/menu`）へ遷移する。
4. 失敗時・通信エラー時は、トースト通知（エラー）で内容を表示し画面に留まる。
5. 「Topページ」ボタン押下で、認証を行わずトップページ（`/`）へ遷移する。

### 特記事項

- ログイン後の遷移で `from` を受け取っている場合は履歴を置き換え、受け取っていない場合は履歴を残す。
- パスワードは画面上伏字表示。
