### ログイン方式

| 項目 | 内容 |
|---|---|
| 採用方式 | 独自 ID・パスワード方式。ログインAPI（`POST /login`）へフォームデータ送信 |
| バックエンド側との対応 | 個人認証マスタログインは使用しない（`bs` 側 SS 工程で別途確定） |
| 実装コンポーネント | ログイン画面（`front-intra-002`） |
| 認証状態の保持方法 | React Context にユーザー情報（ユーザーID・権限）を保持し、ブラウザのローカルストレージのキー `auth` にも保存。サーバ側はセッション（`withCredentials: true` により Cookie を送受信） |

### 共通レイアウト

| 項目 | 内容 |
|---|---|
| ヘッダー・フッター・ナビゲーション構成 | ヘッダーレイアウト（高さ `50px`・背景色 `#00cc99`）＋共通レイアウト（白枠・角丸 `10px`）で全画面を包む。フッターは画面ごとに個別配置（「メニューへ」ボタン等） |
| 実装コンポーネント | ヘッダーレイアウト・共通レイアウト（旧設計書 `00.共通部品.md` 1・2） |

### エラーハンドリング共通方針

| 項目 | 内容 |
|---|---|
| ErrorBoundary 設置範囲 | アプリケーション全体を包む例外捕捉（詳細メッセージはブラウザコンソールに出力し、画面には見出しのみ表示） |
| エラー画面 | エラーページ（見出し「エラーが発生しました。」）／存在しないURLのページ（`404 Not Found`） |
| 実装コンポーネント | エラーページ・存在しないURLのページ（`old_docs/00.共通部品.md` 11・12） |
