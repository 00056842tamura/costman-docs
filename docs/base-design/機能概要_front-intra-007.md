## front-intra-007 管理者用 データ取り込み画面

| 項目 | 内容 |
|---|---|
| 機能ID | front-intra-007 |
| 要件ID | R007 |
| スタック | frontend |
| 種別 | 画面 |

### 機能概要

「社員活動情報データ CSV取り込み」「単価データ CSV取り込み」「ソフ仮データ CSV取り込み」の3つの独立したフォームを提供する。URL: `/admin-torikomi`。ログイン必須かつ管理者権限（`admin`）必須。

### 入力

| 種別 | 名称 | 概要 |
|---|---|---|
| 画面 | 社員活動情報データフォーム | 年月（当月から遡って12か月分）・CSVファイル |
| 画面 | 単価データフォーム | CSVファイル |
| 画面 | ソフ仮データフォーム | 年度（当年度含む3年度分）・CSVファイル |

### 出力

| 種別 | 名称 | 概要 |
|---|---|---|
| API | 社活データアップロードAPI（bs-007） | 年月＋ファイルを送信 |
| API | 単価データアップロードAPI（bs-009） | ファイルを送信 |
| API | ソフ仮データアップロードAPI（bs-008） | 年度＋ファイルを送信 |

### 処理概要

1. 初期表示時、権限が `admin` であることを確認する（`admin` でない場合はメニュー画面へリダイレクト、未ログインの場合はログイン画面へ遷移）。
2. 「年月」「年度」の選択肢を生成し、最新の値を初期選択する。
3. 各フォームの「送信」ボタン押下で、そのフォームのみ単体項目チェックを行い成功時に対応するAPIへ送信する。他のフォームには影響しない。
4. 成功時、そのフォームのみ入力状態を初期化しトースト通知（登録件数）を表示する。他フォームの入力内容は保持される。
5. 失敗時・通信エラー時は入力内容を保持したまま画面に留まり、再送信可能とする。
6. 「メニューへ」ボタンでメニュー画面へ遷移する。

### 特記事項

- 管理者権限による表示制御はクライアント側の抑止的制御に留まり、3つのアップロードAPIの認可判定はサーバ側で行う。
- 3フォームの送信ボタンは同時には押下できない（ローディング表示中は全体をブロック）。
